# Changelog

All notable changes to the Bobbin VS Code extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-01-XX

### Added

- Syntax highlighting for `.bobbin` files
- Error diagnostics via Language Server Protocol
- Autocomplete for variables (temp, save, extern)
- Autocomplete for keywords (save, temp, set, extern)
- Autocomplete for boolean literals (true, false)
- Context-aware completions inside interpolations `{}`
- Bundled language server for zero-setup experience
